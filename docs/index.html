Overview

Study past exams with evidence, not guesswork.

The Question Paper Analyzer helps students and faculty review historical exam data, detect frequently repeated topics, and compare exam patterns across academic years. It stores papers, questions, marks, units, and topics in a structured database and supports semantic similarity matching for different wording of the same concept.

Features

What the system can do

Paper ingestion

Create exam papers, assign subjects and semesters, and store question-level data.

Academic catalog

Manage subjects, units, topics, semesters, and question types from a central catalog.

Pattern analytics

Measure topic frequency, unit weightage, question-type distribution, and semester trends.

Semantic search

Find conceptually similar questions even when wording differs across papers.

Run locally

Local development steps

  1. Open the backend folder.
  2. Create or configure PostgreSQL and run the SQL schema in exam_pattern_ddl.sql.
  3. Install dependencies.
  4. Set DATABASE_URL.
  5. Run: uvicorn app.main:app --reload
  6. Open the app at http://127.0.0.1:8000
